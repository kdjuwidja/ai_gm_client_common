# ai_gm_client_common

The client code every ai_gm product's client and the platform admin client share: the sign-in flow, the
API helper, and behaviour-only UI primitives. Each product keeps its own look.

Released by git tag; clients depend on it as `github:kdjuwidja/ai_gm_client_common#<tag>`.

It is being taken from Nightshade's client under
[workspace ADR 001](https://github.com/kdjuwidja/ai_gm_workspace/blob/main/docs/adr/001-platform-split.md).
